\section{Ход работы}

Основная часть посвящена системе Doxygen. Для документирования использован проект
Beatstore Backend: серверное приложение музыкального каталога на Python.
Примеры описаний рассмотрены на классе \texttt{TagRepository},
а наследование -- на модели \texttt{Product}.

\subsection{Комментирование исходного кода по правилам Doxygen}

В файле \texttt{repository.py} подготовлены специальные комментарии.
Блок документации начинается с \verb|##|, последующие строки --- с \verb|#|.
Использованы команды \texttt{@file} для файла, \texttt{@brief} для краткого
описания, \texttt{@details} для подробного описания, \texttt{@param} для
параметров, \texttt{@return} для результата, \texttt{@var} для атрибута
и \texttt{@note} для особенностей реализации [2, 3].

Фрагмент комментария к классу имеет следующий вид:

\begingroup
\small
\renewcommand{\ttdefault}{\rmdefault}
\begin{verbatim}
## @brief Репозиторий тегов.
# @details Выполняет запросы к тегам через переданную асинхронную
# сессию SQLAlchemy.
class TagRepository:
\end{verbatim}
\endgroup

Аналогично описаны конструктор, методы получения тегов и атрибут
\texttt{session}. Для поиска по идентификатору указаны входной параметр
\verb|tag_id|, результат \verb!Tag | None! и загрузка связанных продуктов.
Эта загрузка выполняется через \verb|selectinload(Tag.products)|.
Сохранённый файл содержит одновременно реализацию и сведения для
генератора справки.

\subsection{Запуск Doxygen и настройка проекта}

В соответствии с методическими указаниями настройка включает название проекта,
каталог исходников, рекурсивное сканирование и каталог результата.
Для рассматриваемого Python-проекта выбираются файлы \texttt{.py},
а кодировка входных файлов должна соответствовать UTF-8.
Русские заголовки полученных страниц отражают выбор русского языка
документации.

Ниже приведён пример параметров \texttt{Doxyfile} для воспроизведения
такой документации с обоими форматами вывода [4].
Пути заданы относительно корня документируемого проекта:

\begingroup
\small
\begin{verbatim}
PROJECT_NAME       = "Beatstore Backend"
INPUT              = .
FILE_PATTERNS      = *.py *.dox *.md
RECURSIVE          = YES
INPUT_ENCODING     = UTF-8
OUTPUT_LANGUAGE    = Russian
OUTPUT_DIRECTORY   = docs
OPTIMIZE_OUTPUT_JAVA = YES
SOURCE_BROWSER     = YES
GENERATE_HTML      = YES
GENERATE_RTF       = YES
GENERATE_LATEX     = NO
CLASS_GRAPH        = YES
\end{verbatim}
\endgroup

Параметр \verb|SOURCE_BROWSER| обеспечивает переход к исходному тексту,
а \verb|CLASS_GRAPH| включает отображение наследования.

\subsection{Генерация документации и просмотр результата}

Для создания шаблона настроек и запуска генератора из корня проекта
используются команды:

\begingroup
\small
\begin{verbatim}
doxygen -g Doxyfile
doxygen Doxyfile
\end{verbatim}
\endgroup

После настройки в графическом интерфейсе аналогичный запуск выполняется
на вкладке Run кнопкой Run Doxygen. Для приведённых выше путей HTML-справка
открывается через \texttt{docs/html/index.html}, а RTF-документ ---
через \texttt{docs/rtf/refman.rtf} в текстовом редакторе, поддерживающем RTF.
Формат RTF включается параметром \verb|GENERATE_RTF = YES| [4].

Предоставленные результаты демонстрируют просмотр HTML-страниц в браузере.
