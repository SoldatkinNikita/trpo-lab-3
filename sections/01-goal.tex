\section{Задание}

\subsection{Введение}

Автоматическое документирование позволяет получать справочные материалы
непосредственно из исходного кода и комментариев разработчика. В лабораторной
работе этот подход рассмотрен на примере Doxygen и серверного проекта
Beatstore Backend на языке Python. Основная часть посвящена подготовке
комментариев, настройке генератора и анализу полученной документации.
В дополнительном задании рассмотрена генерация кода с помощью GitHub Copilot.

\subsection{Цель работы}

Изучить Doxygen и получить навыки автоматического документирования
проекта, файлов, классов, методов и атрибутов. Освоить применение
GitHub Copilot для реализации методов по комментариям и проверки
предложенного кода.

\subsection{Средства выполнения}

\begin{itemize}
	\item редактор Visual Studio Code с расширением GitHub Copilot;
	\item система Doxygen и браузер для просмотра HTML-документации;
	\item исходный код проекта Beatstore Backend на языке Python;
	\item библиотеки SQLAlchemy и компоненты проекта для работы с тегами
	и моделями музыкального каталога.
\end{itemize}

\subsection{Задачи}

\begin{enumerate}
	\item Подготовить комментарии в формате Doxygen для исходного кода
	и сохранить файлы проекта.
	\item Рассмотреть настройку проекта в Doxygen, генерацию HTML и RTF
	и просмотр результатов документирования.
	\item Продемонстрировать краткое и подробное описание класса и его методов,
	входные параметры и возвращаемые значения, атрибуты класса, описание
	проекта и файла со ссылкой на него, а также производный класс.
	\item Подготовить в Visual Studio Code проект и класс с методами и свойствами
	для демонстрации GitHub Copilot.
	\item Продемонстрировать предложения кода по четырём видам запросов:
	краткому комментарию и имени функции, подробному описанию её работы,
	описанию алгоритма и описанию вызова функции.
	\item Проанализировать предложенные реализации и определить необходимые
	корректировки.
\end{enumerate}
